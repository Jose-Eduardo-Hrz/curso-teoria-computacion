Hoy aprenderemos a reordenar los símbolos de una expresión regular para que una computadora sepa, sin dudar, qué operación va primero.
Repaso

¿Qué es una expresión regular?

El alfabeto

\(\Sigma = \{a, b\}\)

Es el conjunto de símbolos que podemos usar, como las fichas de un juego de letras.

ab

Cadenas: palabras hechas con fichas

ababbaaab…

Una expresión regular es una receta que describe un conjunto de cadenas, no necesariamente una sola palabra.

ab
Solo la cadena ab
\(\{ab\}\)
a+b
La cadena a o la cadena b
\(\{a, b\}\)
a*
Ninguna, una o muchas a
\(\{\varepsilon, a, aa, aaa, \dots\}\)

\(\varepsilon\) es la cadena vacía: cero fichas.

Dos formas de escribir

¿Qué significa infija?

En notación infija el operador se escribe entre los elementos sobre los que actúa.

Como en aritmética

La gran ventaja

¿Por qué necesitamos la notación posfija?

Infija: hay que pensar

¿Qué se hace primero?

¿(a+b)·a?

primero la unión

Para decidir necesitamos reglas de precedencia o paréntesis.

Posfija: el orden ya está escrito

a ba·① b·a + ② a + (b·a)

Cada operador se aplica, en cuanto aparece, a las piezas que tiene justo antes. ¡Sin paréntesis!

Si quisiéramos (a+b)·a escribiríamos ab+a·: otra posfija, otro significado.

Hagamos explícita la concatenación

En ab hay una operación escondida. El algoritmo solo procesa lo que ve: hay que escribirla.

Resultado(a+b)*·a·b
Pon un · entre X y Y cuando…
X es una letra, ) o *  y  Y es una letra o (

Nunca pongas un ·…

¿Qué es una pila?

Es como una torre de platos: el último plato que pones es el primero que quitas.

Nadie saca un plato de en medio: siempre se toma el de arriba (el tope).
Durante la conversión, la pila guarda operadores y paréntesis que esperan su turno.

Paso 2 · Convertir

El algoritmo de conversión con una pila

Recorre la expresión de izquierda a derecha, un símbolo a la vez. (a+b)*·a·b
Letra del alfabeto va directo a la salida. lee a → salida a
( a la pila, como marca de inicio de grupo. pila: (
Operador · o +: mientras arriba haya un operador de precedencia mayor o igual, sácalo a la salida. Para en ( o con la pila vacía. llega +, arriba · → sale ·
Después, mete el operador actual en la pila. pila: +
) saca operadores hasta el ( y tira los dos paréntesis. pila (+ → sale +
Al terminar la expresión, vacía la pila en la salida (de arriba hacia abajo). pila +· → sale ·+
Caso especial * (unario, regla 4★): su operando ya está completo a la izquierda y nadie pesa más que él, así que pasa directo a la salida. Es lo mismo que meterlo y sacarlo enseguida.
Los paréntesis nunca llegan a la salida, y * no es binario: jamás espera a un segundo operando.
Paso 2 · En JavaScript

El mismo algoritmo, en código

  posfija.js
const PREC = { '*': 3, '·': 2, '+': 1 };
const tope = (pila) => pila[pila.length - 1];
function aPosfija(expr) {   // expr ya trae los «·»
  const salida = [], pila = [];
  for (const c of expr) {
    if (/[a-z]/.test(c)) salida.push(c);         // R2
    else if (c === '(') pila.push(c);            // R3
    else if (c === ')') {                        // R6
      while (tope(pila) !== '(') salida.push(pila.pop());
      pila.pop();                      // tira el «(»
    } else if (c === '*') salida.push(c);        // R4★
    else {                                       // R4 y R5
      while (pila.length && tope(pila) !== '(' &&
             PREC[tope(pila)] >= PREC[c])
        salida.push(pila.pop());
      pila.push(c);
    }
  }
  while (pila.length) salida.push(pila.pop());  // R7
  return salida.join('');
}
console.log(aPosfija('(a+b)*·a·b'));  // ab+*a·b·

¿Cómo se lee?

ab+  elige entre a y b = a+b
ab+*  repite esa elección 0 o más veces = (a+b)*
ab+*a·  concatena una a = (a+b)*a
ab+*a·b·  concatena una b = (a+b)*ab

Primero la unión (dentro del paréntesis), luego la estrella (3) y al final las dos concatenaciones (2), de izquierda a derecha.

Hacia Thompson

¿Cómo sabe el programa qué hacer?

Parsear es leer una expresión y descubrir su estructura. Con la posfija basta una pila de piezas:

x letra → apila una pieza nueva * toma 1 pieza ·+ toman 2 piezas, las combinan y apilan el resultado
Al final queda una sola pieza: la expresión completa. En la próxima sesión, cada pieza será un pequeño AFN y Thompson los unirá con estas mismas reglas.

Errores comunes

Olvidar los ·
(a+b)*ab → ab+*ab
la a y la b quedan sueltas: nadie las une
(a+b)*·a·b → ab+*a·b·
Unión ≠ suma
a+b «junta a con b» → ab
el + no suma ni pega: elige
a+b = \(\{a, b\}\): a o b
No vaciar la pila
a+b·a → aba
se quedaron · y + dentro de la pila
a+b·a → aba·+
Paréntesis en la salida
(ab+)*a·b·
los paréntesis se tiran al cerrar el grupo
ab+*a·b·
Ignorar la precedencia
a+b·a → ab+a·
eso significa (a+b)a, otra expresión

(a+b)* → *ab+
